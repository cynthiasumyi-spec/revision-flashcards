# 小六英文生字卡（Revision Flashcards）

https://cynthiasumyi-spec.github.io/revision-flashcards/

## 內容
- `index.html` — 首頁（Unit 1–4 + Dictation 3）
- `unit1/` … `unit4/` — **互動網頁生字卡**（音節、中文詞性、例句／進階例句、🔊 讀音；附小圖）
- `dictation3/` — 既有 Dictation 3 **圖片字卡**（點圖放大 + 🔊）

## 上傳步驟（手動）
1. 到 GitHub 倉庫 `cynthiasumyi-spec/revision-flashcards`（若尚未建立請先新建，並啟用 Pages：Settings → Pages → Deploy from branch `main` / root）
2. 將本 zip 解壓後的**全部檔案**放到倉庫根目錄（要看到根目錄有 `index.html`）
3. Commit & Push
4. 約 1–2 分鐘後開啟上述網址
